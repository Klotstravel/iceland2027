# Исландия лето 2027 — iceland2027.klotstravel.com

Страница тура Klots Travel (перенос с Тильды, klotstravel.com/iceland2027summer).

- `index.html` — готовая страница (собирается, руками не править).
- `src/template.html` — разметка, стили и скрипты; `src/program.json` — программа по дням; `src/reviews.json` — отзывы.
- `img/` — фото (уменьшены для веба), `fonts/` — шрифт Jost (SIL Open Font License).
- Сборка: `python3 src/build.py` (пилот, закрыт от поисковиков) или `python3 src/build.py --public`.
